SKYSPY FUEL – OPRAVA OHRAZENICE + NÁHRADNÍ ČTENÍ TURNOVA

Obsah ZIPu není celý Android projekt. Jsou to 4 změněné soubory sběrače a tento návod.

1. ZIP rozbal.
2. Otevři GitHub Desktop > skyspy-fuel > Repository > Show in Explorer.
3. Z rozbaleného ZIPu PŘETÁHNI soubory A SLOŽKY do složky skyspy-fuel
   (nikoliv celou nadřazenou složku ZIPu). Potvrď PŘEPSAT SOUBORY.
4. V GitHub Desktop klikni Changes, napiš "Oprava Kontakt Ohrazenice"
   do Summary, klikni Commit to main a Push origin.
5. Na GitHubu otevři Actions > SKYSPY FUEL – aktualizace cen > Run workflow.
6. Ověř https://waverapnbeatz-tech.github.io/skyspy-fuel/prices.json
